# Illumini take-home

Read [BRIEF.md](BRIEF.md) first, then the first commit is `PLAN.md`, before any code.

1. Click "Use this template" then "Create a new repository", make it Private in your own account, and clone it.
2. `cp .env.example .env` and paste the key emailed to you.
3. `make dev` (Python 3.11+; Windows: run the three commands in the Makefile by hand, using `.venv\Scripts\`).
4. `make run` (writes `runs/<timestamp>/profile_a_matched.jsonl`), `make test`.

Submit by adding `b-lynch` as a collaborator on your repo and emailing the link to blynch@illumini-technology.io.
